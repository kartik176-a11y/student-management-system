
# 🎓 Student Management System

A responsive Student Management System built using HTML, CSS, and JavaScript. This project allows users to manage student records through a simple and colourful dashboard.

## 🚀 Live Demo

[View Live Website](https://kartik176-a11y.github.io/student-management-system/)

## 📌 Project Overview

The Student Management System is a front-end web application designed to simplify basic student record management. Users can add, view, edit, delete, search, and filter student records through an interactive interface.

Student records are stored in the browser using LocalStorage.

## ✨ Features

- **Add Students:** Add new student details.
- **Edit Students:** Update existing student information.
- **Delete Students:** Remove student records.
- **Search Students:** Find students quickly.
- **Filter Records:** Filter student information.
- **Form Validation:** Validate user inputs.
- **LocalStorage:** Save records in the browser.
- **Responsive Design:** Works on desktop, tablet, and mobile screens.
- **Interactive Dashboard:** Easy-to-use interface.

## 💻 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/kartik176-a11y/student-management-system.git
   ```

2. Open the project folder:

   ```bash
   cd student-management-system
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code.

## 🌐 Deployment

This project can be deployed using GitHub Pages.

1. Open the repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and the folder containing `index.html`.
5. Save the settings.

## ⚠️ Limitations

- Student records are stored in browser LocalStorage.
- Data is not stored in a central database.
- Records are specific to the browser and device being used.

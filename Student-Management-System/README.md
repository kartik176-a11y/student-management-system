# Student Management System
Responsive student-record management website using HTML5, CSS3 and vanilla JavaScript.

## Features
- Add, edit and delete student records.
- Validate required fields, email format and duplicate roll numbers.
- Search by name, roll number or email; filter by department.
- Dashboard counts and browser LocalStorage persistence.
- Responsive layout using CSS Grid, Flexbox and media queries.

## Structure
- `index.html` — semantic page structure
- `css/style.css` — styling and responsive layout
- `js/script.js` — form, validation, DOM events and LocalStorage
- `screenshots/` — add your own genuine screenshots here

## Run locally
Open this folder in VS Code and run `index.html` with Live Server, or open it directly in a browser.

## GitHub Pages
Push the project to a GitHub repository. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. Wait for GitHub Pages to publish the site.

## Privacy
This demonstration stores records only in the current browser's LocalStorage. It has no server or shared database. Do not enter real or sensitive student data.
